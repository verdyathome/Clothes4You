# Users, profiles and passwords

Everyone logs in with their own username and password. Each login has a **profile**:

| | User | Admin |
|---|---|---|
| Record and view purchases, items, sales, refunds, expenses | ✓ | ✓ |
| Import eBay sales, download Excel, read Help | ✓ | ✓ |
| Change their own password | ✓ | ✓ |
| **Add, amend and delete logins** (Users page) |  | ✓ |
| **Settings** (name, colours, icon, login photo) |  | ✓ |

## Changing your own password

Open the **☰ menu** (or **Change password** at the top right on a computer), enter your current password, then the new one twice. Passwords must be at least 10 characters and can't contain your username. A short sentence works well, e.g. *three pink coats on Tuesday*.

## For Admins: managing logins

Open **Users** from the menu.

- **+ Add user**: choose a username (letters and numbers, no spaces), the name shown in the app, the profile, and a password. **Tell the person their password yourself.** The app stores passwords scrambled, so nobody (Admins included) can look them up later.
- **Edit** (tap a name): change the name shown, the profile, or **Status**. Setting Status to **Disabled** stops someone logging in without deleting them. To reset a forgotten password, type a new one under **Set a new password**.
- **Delete user**: tap it **twice** to confirm. The login is removed and they're signed out straight away. Their past sales and expenses stay.

## Safety rules

- There must always be at least one active Admin: the last Admin can't be deleted, disabled or changed to User.
- You can't delete or disable your own login.
- After **5 wrong passwords**, that username is locked for **15 minutes**.
- Changes to someone's profile or status take effect on their next tap. They don't need to log out.
